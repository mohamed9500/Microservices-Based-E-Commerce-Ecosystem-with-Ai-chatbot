# Microservices-Based-E-Commerce-Ecosystem-with-Ai-chatbot
A scalable E-Commerce platform built with Microservices Architecture using ASP.NET Core, C#, Entity Framework Core, SQL Server, Docker, RabbitMQ, Redis, JWT, and API Gateway. Includes independent services for products, users, carts, orders, payments, inventory, and notifications, demonstrating modern distributed system design.
